Moving a home server to a new disk

My old disk started throwing read errors last week, so I bought a new one and I am trying to work out how to move everything over without reinstalling. The machine runs a few containers and a file share for the family. I have a spare USB enclosure. Is cloning the whole disk the way to go, or should I copy the data and set the system up again from scratch?

second_author•3h ago

I did this in the spring. Cloning worked, but I had to fix the boot entry afterwards because the new disk got a different identifier, and it took me an evening to find out why it would not start. If your containers keep their data in one directory I would honestly just copy that and reinstall, it is less to go wrong and you get rid of years of leftovers.

fifth_author

Late to this, but check the power-on hours of that enclosure before you trust it with the only copy of anything. Mine dropped off the bus twice during a long copy and I only noticed because the checksums did not match at the end. I ended up doing the transfer over the network from another box instead, which was slower but at least it finished.
